# Manuscript Figures

Generated by `scripts/make_figures.py` from the tracked clean data and reports.
Each figure is saved as a vector PDF (for the manuscript) and a PNG (preview).

- `fig1_p300_by_chronotype` — **Primary finding.** Posterior P300 loss-minus-gain
  amplitude for Evening vs Morning at Pz and POz, with participant points,
  group means with 95% CIs, and effect sizes (Pz d = -1.04, FDR p = 0.034;
  POz d = -0.92, FDR p = 0.045).
- `fig2_sensitivity_forest` — Robustness across participant-exclusion scenarios.
  Left: P300 Cohen's d with 95% CI stays near -1.0 in every scenario. Right:
  the exploratory classifier's permutation p, which rises above 0.05 when the
  label-conflict participants are removed. Visualizes "neural effect robust,
  classifier fragile".
- `fig3_feature_importance` — Held-out permutation importance for the compact_12
  logistic regression. `Pz_P300_loss_minus_gain` dominates.
- `fig4_risky_choice_baselines` — Risky-choice balanced accuracy by feature pack
  under participant-grouped CV, against majority, persistence, and
  participant-mean-oracle reference lines.
- `fig5_meq_continuous_p300` — Posterior P300 loss-minus-gain vs the continuous
  MEQ score (Pz, POz) with OLS fit, points colored by binary label, and the MEQ
  intermediate band (42-58) shaded. Confirms the effect is a graded association
  with morningness, not an artifact of dichotomization.
- `fig6_ml_pipeline` — Schematic of the leakage-aware nested cross-validation
  machine-learning workflow (preprocessing fit inside folds, inner-loop tuning).
- `fig7_roc` — Out-of-fold ROC curve for the primary chronotype classifier
  (compact_12 logistic regression; pooled AUC 0.79).
- `fig8_confusion_matrix` — Out-of-fold confusion matrix for the primary
  classifier (28/39 correct; sensitivity 0.75, specificity 0.68).
- `fig9_chronotype_from_dynamics` — **Deep-learning/computational strand.**
  Left: permutation null vs. observed nested-LOO AUC for chronotype decoded from
  the GRU behavioral embedding (AUC 0.713, p = 0.027). Right: out-of-fold decision
  score vs. continuous MEQ. Generated by `scripts/dl/make_dynamics_figure.py`
  (not `make_figures.py`); see `scripts/dl/README.md`.
