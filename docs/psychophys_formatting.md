# Psychophysiology Formatting Shell

Formatting draft for a single integrated manuscript targeting `Psychophysiology`. This file is a checklist and boilerplate source only; it intentionally avoids scientific claims and final numerical results.

## Structured Abstract Skeleton

**Background:** [One to two sentences stating the broad problem and why feedback processing, chronotype, and decision-making are linked.]

**Methods:** [Participants, task, EEG/ERP measures, behavioural/computational analyses, and leakage-safe evaluation approach.]

**Results:** [Primary ERP finding, behavioural/computational convergence, null/deep-learning boundary result, and robustness/equivalence/Bayes-factor additions after review.]

**Conclusions:** [Interpretation of what the integrated evidence contributes, with appropriate small-sample caution.]

**Keywords:** chronotype; feedback-related negativity; P300; event-related potentials; risky decision-making; reinforcement learning; machine learning

## Data And Code Availability Boilerplate

Select and edit one option after the team decides what can be shared.

**Open data/code option:** De-identified analysis data, analysis scripts, and reproducibility instructions are available at [repository URL or DOI]. Raw EEG data are available [publicly / on reasonable request / subject to institutional approval] because [privacy, consent, and file-size constraints].

**Controlled data option:** Analysis scripts and aggregate/de-identified derivative tables are available at [repository URL or DOI]. Raw participant-level EEG/behavioural data are not publicly posted because [consent/privacy/institutional constraints], but requests for access may be directed to [contact] and will be reviewed under [institutional/data-use process].

**No public participant data option:** Analysis code and non-identifying summary artifacts are available at [repository URL or DOI]. Participant-level data are not publicly available because [ethics/consent/privacy constraints].
